# GlideClient-Launcher

This is an unofficial launcher for GlideClient (formerly SoarClient), created by the GlideClient Team.

As it is open source, we assure you that it is safe to use. However, please note that since this is not an official release, there is a possibility that this repository may be removed in the future.

We would like to express our sincere gratitude to the GlideClient team for developing and sharing GlideClient.
